# 塔罗牌图片资源目录 (Tarot Card Images)

您可以在此目录放入 78 张塔罗牌图片。

### 支持的文件命名方式（任选一种即可）：
1. **按卡牌编号命名**（最推荐）：
   - `0.jpg` 到 `21.jpg`（大阿卡纳：0号愚人到21号世界）
   - `22.jpg` 到 `35.jpg`（权杖一到国王）
   - `36.jpg` 到 `49.jpg`（圣杯一到国王）
   - `50.jpg` 到 `63.jpg`（宝剑一到国王）
   - `64.jpg` 到 `77.jpg`（星币一到国王）
   - 支持 `.jpg` 与 `.png` 格式。

2. **按英文名称命名**：
   - 如 `the_fool.jpg`, `the_magician.jpg`, `the_high_priestess.jpg` 等。
   - 或 `thefool.jpg`, `themagician.jpg` 等。
